# Changelog

All notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-12

### Added

- Goodreads, StoryGraph, generic CSV, and pasted-text reading-list import.
- Local Tesseract.js OCR with quick and three-orientation shelf modes.
- Inspectable fuzzy matching with Found, Review, and Missing states.
- JSON scan receipts, CSV export, local session restore, and explicit reset.
- Responsive PWA interface, sample data, unit coverage, browser E2E, real OCR E2E, CI, Pages deployment, and deterministic release archives.
